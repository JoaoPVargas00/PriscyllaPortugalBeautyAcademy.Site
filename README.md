Priscylla Portugal Beauty Academy

Site institucional desenvolvido para a Priscylla Portugal Beauty Academy, com o objetivo de apresentar a profissional, divulgar seus cursos, procedimentos estéticos, resultados e facilitar o contato com clientes e alunas.

O projeto possui uma identidade visual elegante e moderna, voltada para o segmento de beleza, estética e micropigmentação.

⸻

Sobre o projeto

A plataforma apresenta os principais serviços oferecidos por Priscylla Portugal, profissional com mais de 10 anos de experiência na área da estética e micropigmentação.

Além dos atendimentos, o site também divulga os cursos da Priscylla Portugal Beauty Academy, voltados para profissionais que desejam se especializar e crescer no mercado da beleza.

⸻

Funcionalidades

* Página inicial com apresentação profissional
* Seção sobre a trajetória de Priscylla Portugal
* Apresentação dos cursos da Beauty Academy
* Catálogo de procedimentos estéticos
* Botões de agendamento pelo WhatsApp
* Depoimentos de clientes e alunas
* Slider de depoimentos com controles de navegação
* Informações de endereço e localização
* Integração com Google Maps
* Links para Instagram, TikTok, Facebook e WhatsApp
* Menu responsivo para dispositivos móveis
* Botão flutuante do WhatsApp
* Animações durante a navegação
* Preloader personalizado
* Layout adaptado para computadores, tablets e celulares

Como executar o projeto

1. Faça o download ou clone este repositório:

git clone URL-DO-REPOSITORIO

2. Acesse a pasta do projeto:

cd priscylla-portugal-beauty-academy

3. Abra o arquivo index.html no navegador.

Também é possível utilizar a extensão Live Server no Visual Studio Code para executar o projeto localmente.
